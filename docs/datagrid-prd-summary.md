# DataGrid PRD 提炼（当前版本）

> 来源：`/Users/wuyuhui/Downloads/表格组件prd.pdf` 与你上传的顺序截图  
> 目标：把复杂表格能力拆成可落地的 React 组件规范

## 1. 组件定位
- 用于大量结构化数据展示 + 操作处理（排序、筛选、分组、行选中、编辑、列配置）。
- 支持作为产品统一表格底座，在不同业务页复用。

## 2. 核心规则（提炼）
- 列宽规则：
  - 每列有最小宽度（默认 100px）与最大宽度（默认 700px）。
  - 支持手动拖拽调整列宽，受最小/最大宽度约束。
- 列布局规则：
  - 支持列显隐、列顺序调整、重置为默认布局。
  - 第一列可设置为受保护列（不允许隐藏/拖动）。
- 单元格内容响应：
  - 支持 `截断`、`换行` 两种主模式。
  - 超长文本默认截断，保留 title 提示。
- 列类型（当前范围）：
  - 文本、数值、日期、日期区间、布尔、枚举。
- 行交互：
  - 行选中支持 `checkbox` 和 `单击` 两种模式。
  - 支持单选/多选；多选支持快捷键追加与 Shift 范围选择。
- 快捷操作：
  - 表头菜单支持：升序、降序、按列分组、筛选、隐藏列、对齐方式。
- 分组逻辑：
  - 当前按单列分组，一次仅激活一个分组字段。

## 3. 当前实现状态（代码）

### 已实现
- 列显隐、列顺序、重置。
- 列宽拖拽（最小/最大宽度限制）。
- 单列排序（升序/降序/取消）。
- 列筛选（包含匹配）。
- 单列分组（可折叠组）。
- 行选中（checkbox / click，含多选、快捷键选择）。
- 单元格编辑（文本/数值/布尔/枚举）。
- 行状态样式（默认、选中、禁用、锁定、警告等）。
- 视图配置本地记忆（`localStorage`）。

### 部分实现
- 日期区间“可读性优化”已做基础版本（常见整年/整月区间简写）。
- 列属性配置支持基础项（对齐、换行、显隐、顺序），高级格式项未完整覆盖。

### 未实现（后续迭代）
- 冻结列方向完整能力（左/右冻结细粒度控制）。
- 多字段组合筛选（当前为单字段包含筛选）。
- 多级排序（当前单列排序）。
- 更完整的数据类型格式化面板（科学计数法、复杂日期模板等）。
- 分组聚合统计（当前仅分组展示，不做聚合汇总）。
