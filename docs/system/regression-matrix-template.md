# 轻量回归矩阵模板（Template）

> 本模板是执行载体，不写详细步骤。  
> 填写规则：`[x]` 通过，`[ ]` 未执行，`[!]` 失败；失败仅写一行备注与定位线索。

## 列定义
- 可达：对应 `RULE-001`
- 可用：对应 `RULE-002`
- 可回退：对应 `RULE-003`
- 无阻断：对应 `RULE-004`
- 类型补充断言：按场景引用 `RULE-101+`

## 执行最小集
- 若只改一个模块：至少执行 `ENTRY-001/002` 中 1 条 + `FLOW-001/002/003` 中 1 条 + 对应 `MOD-*` 1 条。
- 若改导航/路由：`MOD-003` 和 `MOD-004` 必选。
- 若改权限：`MOD-005` 必选。
