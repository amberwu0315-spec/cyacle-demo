# 回归触发器表（Regression Triggers）

> 目标：改动发生后，不翻 56 条 TC，也能直接知道“要测什么、按哪条规则测”。

## 使用方式
1. 先定位本次改动类型（可多选）。
2. 按“必回归范围”执行轻量回归。
3. 勾选 `docs/system/regression-matrix-template.md` 并记录备注。

## 触发器清单

| 改动类型 | 必回归范围 | 对应规则 |
|---|---|---|
| IA/菜单结构（L1/L2/L3、分组、命名） | 关键入口可达、菜单切换后内容正确、错误目标兜底 | `RULE-001` `RULE-002` `RULE-401` `RULE-403` |
| 路由参数与深链（`l1/l2/l3/target`） | URL 与状态同步、刷新恢复、非法参数回退 | `RULE-001` `RULE-401` `RULE-403` |
| 导航状态机（前进/后退、Tab、历史栈） | 同链路回放一致、详情 Tab 关闭后默认落点正确 | `RULE-003` `RULE-402` `RULE-403` |
| 工作台卡片/快捷入口 | 卡片点击可达、跨 L1 跳转落位正确、无错页 | `RULE-001` `RULE-002` `RULE-401` |
| 列表页交互（双击、选中、切换） | 列表可用、进入详情正确、返回后上下文保留 | `RULE-002` `RULE-003` `RULE-101` `RULE-103` |
| 主从布局/详情渲染器 | 左右栏联动、详情和选中项一致、返回链路可用 | `RULE-002` `RULE-003` `RULE-101` `RULE-103` |
| 创建入口/创建容器 | 入口可达、取消返回稳定、无状态残留 | `RULE-001` `RULE-003` `RULE-102` |
| 默认值策略（含动态默认值） | 初始默认值正确、展示值与提交值一致 | `RULE-201` `RULE-203` |
| 必填与表单校验 | 缺失/非法输入阻止提交、提示可读可定位 | `RULE-202` `RULE-204` |
| 提交逻辑（保存、成功跳转、失败处理） | 成功后状态可回查、失败有提示、重复提交被抑制 | `RULE-203` `RULE-204` `RULE-004` |
| Footer 弹层（开关、链路） | 打开/关闭稳定、列表详情创建链路、遮罩清理 | `RULE-301` `RULE-302` `RULE-003` `RULE-004` |
| Drawer 抽屉（打开条件、关闭恢复） | 抽屉生命周期完整、关闭后主页面可交互 | `RULE-303` `RULE-003` `RULE-004` |
| 权限角色/可见范围 | 受限入口兜底、角色切换后可恢复到合法页 | `RULE-001` `RULE-404` `RULE-403` |
| 全局组件（Header/Footer/Sidebar） | 关键入口不丢失、回退链路不破坏、无阻断 | `RULE-001` `RULE-003` `RULE-004` |
| 错误边界/异常处理 | 主链路不中断、错误可见且可恢复 | `RULE-004` `RULE-204` |

## 最小执行建议
- 小改动：至少执行 1 条入口 + 1 条核心路径 + 1 条对应类型补充断言。
- 中改动：覆盖触发器对应范围中的全部“必回归范围”。
- 大改动（导航/路由/权限）：追加一次导航回归脚本与矩阵全量核对。
