# 测试用例目录说明

## 目录目的
用于存放页面级、流程级测试用例，服务复杂交互回归测试。

## 命名建议
- 文件名：`TC-<模块>-<序号>.md`
- 示例：
  - `TC-DatabaseManagement-001.md`
  - `TC-ComponentPage-001.md`

## 优先级约定
- `P0`：主流程阻断即不可交付
- `P1`：高频流程，影响核心体验
- `P2`：低频或边缘流程

## 维护规则
- 每次关键交互变更后，至少更新对应模块的 `P0/P1` 用例。
- 阶段提测前，必须执行 A 类页面的 `P0` 用例。
- 用例执行结果需同步到 `docs/qa/stage-review-log.md`。
