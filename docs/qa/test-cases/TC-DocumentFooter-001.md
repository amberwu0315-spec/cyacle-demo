## 测试步骤
1. 点击 Footer `文档` 按钮打开弹层。
2. 检查文档列表与搜索框展示。
3. 检查顶部是否不存在 `添加/创建` 入口。
4. 双击任意一行进入详情，再返回列表。
5. 关闭弹层。

## 预期结果
1. 文档弹层可正常打开。
2. 列表与详情切换链路正常。
3. 创建入口按设计隐藏。
4. 关闭后弹层消失。
