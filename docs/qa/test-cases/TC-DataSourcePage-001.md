# TC-DataSourcePage-001

## 用例信息
- 用例ID：`TC-DataSourcePage-001`
- 页面/模块：`DataSourcePage`
- 用例标题：服务企业数据源页支持空提交创建并可进入主从详情返回
- 优先级：`P0`
- 前置条件：
  - 应用可正常启动
  - 当前账号可进入 `L1 服务企业 -> 全部服务企业`
  - 列表中至少存在 1 条服务企业数据
- 测试数据：无需新增数据

## 测试步骤
1. 进入 `服务企业 -> 全部服务企业`，打开任一主体详情并切换到 `数据源`。
2. 点击右上角 `创建`，不填写字段直接提交创建。
3. 在主从详情页点击 `返回列表`。
4. 在列表页双击任意一行数据，再次点击 `返回列表`。

## 预期结果
1. 数据源列表展示正常，页面可达。
2. 空表单可提交成功，并自动进入新建记录详情页。
3. 可从详情页返回列表页，流程无报错。
4. 列表双击可进入详情，且可再次返回列表。
