# 验收清单

## 1. 全局必验（每次开发）
- [ ] 代码通过 `npm run lint`
- [ ] 关键链路改动后通过 `npm run build`
- [ ] 未引入重复 Header（双栏页面）
- [ ] 未破坏导航切换和返回链路

## 2. 页面通用验收（按页面勾选）
- [ ] 页面可达（导航能进入）
- [ ] 核心内容可见，无阻塞报错
- [ ] 表单遵循 `14px/36px/4px` 规则
- [ ] 操作反馈可见（提示、状态变化）
- [ ] 退出/返回路径明确

## 3. 列表页验收
- [ ] 列表默认展示正常
- [ ] 右上创建按钮行为正确（如适用）
- [ ] 双击行进入详情（如适用）
- [ ] 无数据空态可用

## 4. 创建页验收
- [ ] 进入创建页路径正确
- [ ] 取消返回路径正确
- [ ] 保存后行为正确（提示/返回）
- [ ] 必填校验符合预期

## 5. 主从页验收
- [ ] 左栏切换项生效
- [ ] 右栏显示对应详情
- [ ] 右栏“返回列表/收起”可回到列表页
- [ ] 详情区占位模块结构完整

## 6. FooterModel 验收
- [ ] 弹层可打开/关闭
- [ ] 默认表格显示正常
- [ ] 双击可进入详情
- [ ] 收起可返回表格
- [ ] 创建态可进入并退出

## 7. Drawer 验收
- [ ] 打开条件正确
- [ ] 可关闭且不残留遮罩
- [ ] 不影响主页面滚动与交互
