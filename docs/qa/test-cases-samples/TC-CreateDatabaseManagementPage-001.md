# TC-CreateDatabaseManagementPage-001

## 用例信息
- 用例ID：TC-CreateDatabaseManagementPage-001
- 页面/模块：CreateDatabaseManagementPage
- 用例标题：数据库创建页必填与默认值规则生效
- 优先级：P0
- 前置条件：
  - 应用可正常启动
  - 当前账号可进入 L1 背景数据 -> L2 数据库管理
- 测试数据：
  - 数据库简称：`DB-TEST-001`
  - 数据库全称：`Database Test Full Name`
  - 版本：`1.1`
  - 年份：`2026`
  - 数据库描述：`用于验证创建页规则`

## 测试步骤
1. 进入数据库管理列表页。
2. 点击创建进入创建页。
3. 校验默认值：数据库简称/数据库全称/数据库描述为空；来源固定为`自建`；版本默认为`1.0`；年份默认为当年（2026）。
4. 不填写数据库简称，观察右栏标题和模块提示，并尝试提交。
5. 填写数据库简称，确认右栏标题同步显示该值且不支持手动编辑标题。
6. 确认数据库简称字段右侧存在必填标识，且填写后提交按钮可用。
7. 补充数据库全称、版本、年份、数据库描述并上传 logo 后提交。
8. 取消返回列表（可在本用例末尾执行一次返回链路校验）。

## 预期结果
1. 列表页展示正常。
2. 可进入数据库创建页。
3. 默认值符合规则：来源=`自建`、版本=`1.0`、年份=`2026`，其余指定字段为空。
4. 未填写数据库简称时，不允许提交；右栏标题为红色`<未命名>`；模块提示显示“未维护「数据库简称」”。
5. 填写数据库简称后，右栏标题自动读取该字段值，提交按钮由禁用变为可用。
6. 可上传 PNG/JPEG 格式 logo。
7. 提交后创建成功并进入详情态。
8. 取消可返回列表页。
