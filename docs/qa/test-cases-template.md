## 编写规范
- 一条用例只验证一个核心行为，避免混合多个目标。
- 步骤必须可复现，避免“检查一下”“确认正常”这类模糊描述。
- 预期结果必须可判定（可通过/失败），不要写抽象描述。
- 缺陷必须回链到具体页面与版本。
