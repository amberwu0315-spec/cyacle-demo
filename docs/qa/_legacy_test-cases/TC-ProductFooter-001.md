## 测试步骤
1. 点击 Footer `产品` 按钮打开弹层。
2. 检查搜索框与列表表格展示。
3. 双击任意一行进入详情，点击收起返回列表。
4. 点击 `添加` 进入创建态，再点击取消返回列表。
5. 关闭弹层。

## 预期结果
1. 产品弹层可正常打开。
2. 列表、详情切换链路正常。
3. 创建态可进入并可取消返回列表。
4. 关闭后弹层消失。
