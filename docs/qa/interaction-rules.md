# 交互规则单一真相（SSOT）

## 1. 目标
本文件用于沉淀可复用的交互/视觉硬约束。任何模型协作、页面开发、样式调整都必须先遵循本文件。

## 2. 表单规则（当前版本）
- 标题文字：`14px`
- 内容文字：`14px`
- 标题行高度：`36px`
- 内容行高度：`36px`
- 每个完整表单项间距：`4px`
- 除上述规则外，不允许额外垂直间距
- 例外：`textarea` 可使用多行高度

## 3. 双栏模板规则
- 双栏页面（创建页/主从页/详情页）不显示系统顶部 Header
- 主从页右栏顶部必须有“返回列表/收起”能力
- 主从页至少包含：
  - 左栏可选择列表
  - 右栏详情区
  - 未选中时空状态

## 4. 列表到详情规则
- 列表默认视图：表格
- 进入详情动作：双击表格行
- 详情返回动作：右栏“返回列表/收起”

## 5. FooterModel 复用规则
- `产品/数据/数据源/地点/文献因子/基本流/复合因子/文献/元件` 默认展示表格
- 双击行进入详情
- 详情右栏可收起返回表格
- 与 L2 对应模块复用同一份数据源与交互骨架

## 6. AI 协作执行规则
- 先定义目标、约束、验收，再开发
- 开发后必须跑最小验证：`npm run lint`
- 关键改动后补充验证：`npm run build`
- 完成后更新页面台账与验收清单
